# 时奕教务排课 v0.2.0

Windows 10/11 x64 自签名测试版，延续 v0.1.12 的本地数据与本地排课流程。SignPath 继续暂缓，版本号升级不代表所有网页版功能均已完成迁移。

## 本次改动

- 课表设置：周课程表模板占满侧边栏右侧的可用内容区，移除旧双栏布局预留的 300px 空白栏，保留页面边距。
- 课程计划：指定科目、指定教师、指定教室、清空、应用按钮统一高度并垂直居中，修复“应用”按钮继承表单顶部外边距导致的错位。
- 课程计划：去掉工作区重复外框和建议流程各步骤的边框，保留当前步骤底色及必要的输入控件边界。
- 桌面端、算法服务、项目格式中的应用版本标记与本地预览统一为 0.2.0；未改变数据库结构。
- 增加布局回归检查；桌面样式覆盖保存在独立源文件中，重新同步网页样式时继续保留。

## 下载与安装

下载 `Karios-STT-Desktop_0.2.0_x64-setup.exe`。旁边的 `.exe.sig` 是 Tauri 更新签名文件，不是另一个安装包。

安装前请保存项目并退出旧版本。此发布操作不自动覆盖本机已安装的应用，不修改用户项目数据。

安装包及内置程序使用既有自签名测试证书，并另有 Tauri Ed25519 更新签名；自签名不等于公共 CA 信任。仅构建所需的客户端公开登录配置进入发行版，数据库密码、私钥及 `.env` 不随包分发。

## 发布范围与已知边界

- 本地检查：141 项 Python 测试、21 项 Rust 测试、Ruff、Rust 格式检查和前端类型检查/构建通过。
- 冻结算法服务验证：启动与鉴权、课表配置保存、两轮本地排课及候选续排、五种导出、备份恢复、项目归档、退出无残留均通过。
- 安装包、内置主程序和算法服务的 Authenticode 签名及时间戳通过校验；最终安装包的 Tauri 更新签名验证通过。主程序和算法服务的 Windows 版本资源均为 0.2.0。

- 从独立桌面仓库当前开发分支发布，不直接合并主分支，不部署身份、支付或更新服务器。
- 发布附件包含 SHA-256 清单、源提交信息、依赖清单、CycloneDX SBOM 和公开测试证书。
- 延续 v0.1.12 的功能边界：高级逐课次期望时间、多教室集合、表格批量编辑、科目跳过和相似约束扩展仍待迁移。常见约束仅开放本地算法支持的规则。
- 本轮界面调整尚未完成浏览器截图复核；不将源码样式测试等同于视觉验收。
