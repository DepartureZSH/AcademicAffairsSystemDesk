# 本地排课轮次与候选实现

## 1. 实现边界

本模块复用原 STT 网页项目的纯 Python CP-SAT 算法层，并将其作为桌面 sidecar 的内部包发布。算法输入为本地生成的 XML，输出为本地 XML；运行过程不访问 Supabase、支付、许可证、SMTP 或任何云端排课接口。

复用代码位于 `sidecar/stt_desktop/scheduler_engine/`，桌面编排代码位于 `sidecar/stt_desktop/scheduling/`。OR-Tools 固定为 `9.15.6755`，随 Python sidecar 一同封装。

## 2. 一轮排课的持久化顺序

1. 新建或复用 `optimization_sessions` 优化会话。
2. 新建状态为 `preparing` 的 `scheduling_rounds`。
3. 按当前项目 Revision 读取排课相关表，生成规范化 JSON 快照与 SHA-256 输入哈希。
4. 将快照写入 `artifacts/problem/*-snapshot.json`，将编译输入写入 `artifacts/problem/*.xml`。
5. 状态切换为 `solving`，调用本地 CP-SAT。
6. 第一阶段最大化已安排课次数；完整可行后，第二阶段在剩余预算内优化时间、教室及软约束罚分。
7. 只有所有课次均满足硬约束时才创建 `candidates`、`timetable_entries` 和 `candidate_metrics`。
8. 输入无选项或硬约束不能完整满足时，轮次标记为 `infeasible`，诊断写入 `round_events`，不创建部分候选。

派生的快照、轮次和候选不会修改业务数据 Revision；快照会记录它基于的 Revision，因此可审计候选对应的输入版本。

## 3. 当前编译的约束

- 教师同一时段不重叠：内置硬约束。
- 班级同一时段不重叠：内置硬约束。
- 教室同一时段不重叠：算法内置硬约束。
- 停用教学任务和停用课次不进入输入。
- 连续课时只从作息表中相邻且连续的课节窗口生成。
- 固定教室、教室类型和班级默认教室会生成候选教室。
- 教师、班级、课次和教室可用性会裁剪时间/教室组合；罚分大于零的“避开”规则进入软罚分。
- `same_day_spacing` 编译为同一教学任务课次的不同日条件。
- `preferred_periods` 通过非偏好课节罚分实现。
- `max_daily_lessons` 与 `consecutive_limit` 在候选保存前执行确定性校验；硬约束不通过时不保存候选，软约束按超限量计分。
- 原算法支持的 `NotOverlap`、`SameRoom`、`DifferentTime`、`DifferentDays`、`DifferentWeeks`、`SameDays`、`SameStart`、`SameTime`、`Precedence`、`Consecutive` 可通过参数中的 `lessonIds` 或 `teachingTaskIds` 指定成员。

未识别或成员不足的自定义约束不会静默丢失：编译器会在轮次诊断中写入警告。

## 4. Warm start 与候选保留

首轮使用原项目的贪心结果作为 CP-SAT hint。后续轮次可以指定任一有效候选；sidecar 从该候选的本地 Solution XML 恢复匹配安排并作为新一轮 hint。输入已经变化时，仅仍存在且仍属于合法选项的安排会进入 hint，其余由算法重新求解。

历史候选、父候选关系、输入哈希、评分、求解指标、XML 产物和事件日志均保留，不覆盖上一轮结果。

## 5. 本地接口

- `POST /v1/scheduling/rounds`：运行一轮本地求解；默认 60 秒，允许 10–1800 秒。
- `GET /v1/scheduling/sessions`：列出优化会话。
- `GET /v1/scheduling/rounds`：列出轮次，可按会话筛选。
- `GET /v1/scheduling/rounds/{id}`：读取轮次和诊断事件。
- `GET /v1/scheduling/candidates`：列出候选及课次、评分信息。

这些接口仍受随机端口、一次性 Bearer 令牌、回环地址和 Origin 白名单保护。

## 6. UI 操作

打开项目后进入“排课运行”：

1. 设置会话名称、时长和随机种子。
2. 点击“生成第一轮候选”。
3. 选择任一候选后点击“以上一候选继续优化”。
4. 若硬约束无解，页面显示无解轮次且候选数不增加；详细冲突保存在本地事件日志。

## 7. 验证范围

自动测试覆盖：

- 可行输入生成快照、候选、课表条目和指标；
- 选择父候选后继续一轮并保留父子关系；
- 两个课次争用唯一时间时返回无解诊断且候选表为空；
- 快照不包含认证或许可证数据；
- 空项目通过 HTTP API 返回可审计的无解结果；
- Python 全套测试、Ruff 和 Vue 生产构建。

异步取消、进程级隔离、6000 课次规模验收和候选对比课表属于后续质量与课表模块的验收项。
