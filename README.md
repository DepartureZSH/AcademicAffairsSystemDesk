# 时奕教务排课

时奕教务排课是面向中小学的跨平台本地排课桌面应用。Windows 10/11 x64 为首发平台，桌面壳采用 Tauri 2，排课数据与算法完全保存在本机并在本机运行。

当前仓库处于实施准备阶段。产品范围、架构、授权、测试、签名发布和人工准备要求见 [`docs/desktop`](./docs/desktop/)。

## 当前状态

- 已完成第一阶段需求和架构文档。
- 正在完成 G0 开发环境与公开仓库准备。
- 尚未进入桌面业务代码实现。
