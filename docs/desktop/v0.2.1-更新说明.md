# v0.2.1 台账模板与课次编辑测试版

## 本次变化

- 教室类型、教师、班级、教室台账新增“导出模板”列，新增与详情编辑均可选择本项目普通课表模板；总课表模板不作为单条记录的选项。
- 恢复默认会清除单独指定；教室未指定时显示教室类型的分配，否则显示项目默认模板。科目台账不扩展本次字段。
- 复用现有 `timetable_template_assignments` 表，不创建重复的模板字段或第二套映射。资料与模板指定同一事务保存，过期版本、无效模板或失败的数据库操作全部回滚。删除台账记录同时清理其模板映射。
- 保留现有作息分配规则；本次补充台账的模板选择入口，不改造候选课表的 CSV/XLSX/PDF 明细导出格式，也不宣称已复刻网页版全部自定义打印布局。
- 合并教师工号移除、科目配置完整遮罩、编辑课次及期望时间、本地课次原子保存、表格授课配置计数对齐。

## 项目兼容

本版将旧项目升级到 schema 3。打开旧项目时先自动生成迁移前备份，再移除教师工号并增加课次规划配置。迁移后的项目不能直接由旧版应用打开；回退请使用迁移前备份。详见[迁移说明](课次编辑与教师字段迁移说明.md)。

## 发布方式

Windows x64 NSIS 安装包，沿用专用测试 Authenticode 证书与可信时间戳，最终文件另附 Tauri updater 签名。SignPath 继续暂缓。本地制品位于 `build/release/v0.2.1/`，SHA-256 与签名信息以该目录的 release manifest 为准。

本次 GitHub 同步包含源码、版本标签与测试版安装包，不自动合并主分支、不部署网页版或远端身份服务，也不覆盖用户已安装目录。

## 验证结果

- Python 回归测试 156 项通过；Rust 单元测试 21 项通过；Vue 类型检查、生产构建与 Ruff 检查通过。
- 冻结 Sidecar 实测通过：启动鉴权、课表设置、本地排课与 warm start、五种格式导出、备份恢复、项目归档、关闭后无残留进程。
- 安装包及内部主程序、Sidecar 的 Authenticode/时间戳通过，最终安装包的 updater 签名通过；发行版内嵌公开登录配置检查通过。
- 尚未对 v0.2.1 重新进行干净 Windows 虚拟机安装或已有安装目录的原位升级测试。
