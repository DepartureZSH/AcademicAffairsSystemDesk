# 课程计划与教学任务批量导入

## 1. 模块结果

CSV / Excel 批量导入新增“课程计划”和“教学任务”两类模板，解决新项目必须逐条录入大量任课数据的问题。所有引用只在当前本地 SQLite 中按名称解析，原文件仍复制到项目附件并参与哈希复核，不上传远端。

## 2. 课程计划字段

- 学期名称（可选，未填时继承班级学期）；
- 班级名称、科目名称、每周课时（必填）；
- 连续课时、允许连堂、优先级；
- 周次位图和星期位图。

本地按“学期 + 班级 + 科目”执行文件内和数据库内判重。

## 3. 教学任务字段

- 学期名称（可选，未填时继承班级学期）；
- 班级名称、科目名称、主讲教师、每周课时（必填）；
- 连续课时、要求教室类型、固定教室、状态；
- 周次位图和星期位图。

若当前项目存在唯一匹配的“学期 + 班级 + 科目”课程计划，教学任务自动写入 `course_plan_id`。确认导入时为每个任务生成新的本地 UUID，并按每周课时和连续课时展开 `task_lessons`。例如每周5课时、连续2课时生成3个课次，时长为2、2、1。

教学任务和全部课次通过一次 `bulk_insert_entities` 事务写入，只增加一个 Revision；中途失败时两类记录一起回滚。确认前仍强制创建 `pre-import` 完整备份。

## 4. 验证

自动测试完成课程计划 CSV 预览/确认，再完成教学任务 CSV 预览/确认，验证：

- 班级、科目、教师和学期引用全部重建；
- 未填写学期时正确继承班级学期；
- 教学任务自动关联刚导入的课程计划；
- 1个任务和3个课次同一 Revision 写入；
- 课次时长合计等于任务每周课时；
- SQLite 完整性为 `ok` 且无外键问题。
