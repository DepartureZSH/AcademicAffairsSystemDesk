# v0.2.5 内测版

本版接入网页版 AI 助手的本地业务执行链，替代 v0.2.4 中仅建议性对话和未接通的专项入口。

- 自配 AI 地址、密钥和模型；密钥由系统密钥库保管。
- 五场景查询、工具调用、提案编译、变更审核、确认/拒绝、备份及事务执行。
- 课表 Excel 识别、分区标注、预览与实际保存；官方 Excel 模板下载。
- 课程计划附件逐行导入、覆盖率检查、期望时间专项配置。
- 约束规则搜索、范围识别、相似扩展、模板上传解析与本地算法适配。
- 流式回复与工具片段拼接，连接中断不提交未完成变更。

使用 AI 前会提示数据发送范围和服务地址。服务商可能收到对话、历史附件及按需查询的教务资料；日常排课与项目存储仍在本机。请核对审核清单再确认。

## 安装与验收边界

Windows x64：NSIS 为首选，MSI 为备用。保存并退出旧版后运行安装包；本轮不自动覆盖正在使用的安装目录。SignPath 暂缓，本版沿用未签名内测分发，不作为已签名自动更新发布。

本地自动化及冻结程序检查不替代干净 Windows 虚拟机、真实 AI 提供商和人工业务验收；本次不调用用户真实提供商，不产生接口费用。

发布前验证：214 项 Python 测试、32 项 Rust 测试通过（1 项子进程辅助入口按设计忽略）；Ruff、Rust 格式检查和前端生产构建通过。冻结程序通过启动、AI 五场景工具/模板、本地排课、五类导出及备份恢复检查。发行程序校验确认已包含公开登录配置，未检出 `.env` 中的服务端凭据。
