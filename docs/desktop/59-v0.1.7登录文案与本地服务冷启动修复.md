# v0.1.7 登录文案与本地服务冷启动修复

## 1. 用户侧调整

- 登录、配置异常、加载状态和工作台不再展示 Supabase、WebView、API、随机端口、令牌、SQLite、Schema 等实现术语。
- 登录页改用“时奕账号”“会员权益”“教务数据留在本机”等面向普通用户的说明。
- 不在首次启动页提供服务地址或客户端 Key 输入框；正式测试包继续在构建时写入公开客户端配置。
- 移除普通界面的模拟服务名称，避免把内部环境状态展示给最终用户。

这些调整不改变数据边界：账号和会员权益联网核验，学校、教师、班级、课程、课表和算法输入输出仍只保存在本机。

## 2. 本地服务启动修复

v0.1.6 的 PyInstaller 单文件组件在当前 Windows 11 设备上的冷启动实测超过 14 秒，原 5 秒门槛会把正常解包和安全软件扫描误判为启动失败。

v0.1.7 将冷启动上限调整为 30 秒。进程提前退出时仍立即报错；超时时会同时清理外层启动器和同路径的冻结工作进程，避免留下后台进程。界面在等待期间保持可交互并显示“正在准备本地工作区”。

最终冻结组件实测 16,216 毫秒就绪，健康检查为 `ok`，正常关闭后 launcher/worker 均无残留。
