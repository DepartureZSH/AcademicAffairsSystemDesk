# 时奕教务排课 v0.1.12

本版本是 Windows x64 自签名测试版，SignPath 暂缓。包含此前仅在本地完成的 v0.1.11 页面迁移及修正。

## 界面调整

- 课程计划：新版班级卡片总览、组合筛选、班级详情、逐科/表格视图、科目配置弹窗、同学期班级课程复制。
- 课程计划与排课运行统一 24px 页面内边距，卡片采用 16–24px 留白；正文 14px、辅助文字 12–13px，标题与数值分层。修正排课卡片左右无内边距、窄窗口表格变形与弹窗偏移。
- 课表设置采用当前网页版可视编辑流程；去除教室/教师状态、科目专用教室字段与顶部重复项目栏；同源更新窗口及任务栏图标。
- 弹窗背景不作为关闭入口。本地保存教师/教室元数据时保留课次 ID，复制课程不覆盖目标已有配置。

## 本地安装包

`apps/desktop/src-tauri/target/release/bundle/nsis/时奕教务排课_0.1.12_x64-setup.exe`

旁边的 `.sig` 是 Tauri updater 签名。安装包使用既有自签名测试证书，不等于公共 CA 信任。未将原始密钥、数据库密码、项目数据或 `.env` 放入发行包。构建时仅注入客户端公开登录配置。

## 验证与范围

- 前端类型检查及构建通过；Python 139 项测试通过；Ruff 检查通过。
- Codex 浏览器检查课程计划与排课运行，在 1033px 窗口核对实际字号、卡片内边距与布局。
- 使用独立桌面仓库当前开发分支发布；不直接合并主分支，不部署 Supabase、支付或更新服务器。
- 经用户保存并退出旧应用后，本机原安装目录已升级至 0.1.12；主程序及算法服务与安装包解出的文件 SHA-256 一致。旧程序文件已单独备份，不改用户工作区数据。
- Rust 21 项测试通过，冻结服务排课、候选续排、五种导出、备份恢复、归档与退出零残留检查通过。最终安装包、内置主程序/算法服务的 Authenticode 和时间戳、Tauri updater 签名均通过验证。
- 依赖清单对 `buffers@0.1.1` 的缺失字段作版本限定补充，证据见同目录《v0.1.12-依赖许可证核对》。

## 已知功能边界

本次不是所有网页版功能的完整移植：高级逐课次期望时间、多教室集合、表格批量编辑、科目跳过与相似约束扩展仍待迁移。常见约束目录中仅本地算法支持的 10 类允许保存，其余明确禁用；候选编辑与导出继续使用本地组件。
