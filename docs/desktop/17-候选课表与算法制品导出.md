# 候选课表与算法制品导出

## 1. 支持格式

候选课表页面可以通过 Windows 原生保存对话框导出：

- `.xlsx`：含“候选课表”和“候选信息”工作表，冻结表头、自动筛选、列宽和中文样式已设置；
- `.csv`：UTF-8 BOM，便于中文 Windows Excel 直接识别；
- `.pdf`：A4 横向打印表，使用本机中文字体，重复表头并显示页码；
- `problem.xml`：候选绑定的算法输入；
- `solution.xml`：候选绑定的完整算法输出。

只有 `valid` 且硬约束违例数为零的候选能够导出。

## 2. 文件安全与一致性

导出采用两阶段写入：

1. 在项目 `artifacts/exports/` 中写随机临时文件；
2. 刷盘后原子替换为项目内正式制品；
3. 计算 SHA-256、字节数和行数并写入 `export_jobs`、`artifacts`；
4. 用户通过 Tauri 原生保存对话框选择目标后，再在目标目录使用临时文件和原子替换复制。

数据库只保存项目内相对路径，不保存用户选择的绝对导出路径。目标扩展名必须与格式匹配；已有文件只有在原生保存对话框完成覆盖确认后才允许替换。失败任务记录安全错误摘要，不把课表内容或绝对路径写入日志。

## 3. PDF 字体

Windows 首版按顺序使用微软雅黑或黑体；后续平台可使用 Noto Sans CJK 或苹方。找不到可用中文字体时 PDF 导出明确失败，不生成乱码或方框替代品。

PDF 验证不只检查文件头：自动测试生成中文课表后使用 Poppler 渲染为 PNG，并人工检查标题、中文字符、表格边界、交替行底色、页边距和页脚页码。本次验证页面无文字裁切、重叠、乱码或黑块。

## 4. 原生对话框权限

桌面壳新增官方 `tauri-plugin-dialog 2.7.2`，能力清单只授予：

- `dialog:allow-open`；
- `dialog:allow-save`。

当前导出流程只使用保存对话框。打开权限为下一步本地 CSV/XLSX 导入共用，不授予通用文件系统插件读写权限；实际文件解析和写入仍由受一次性令牌保护的本地 sidecar 完成。

## 5. 本地接口

- `POST /v1/exports`：生成并可选复制一个候选导出；
- `GET /v1/exports`：列出本项目的导出历史及哈希摘要。
