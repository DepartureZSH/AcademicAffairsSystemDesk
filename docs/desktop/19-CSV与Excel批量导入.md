# CSV 与 Excel 批量导入

## 1. 支持对象

当前批量导入支持：

- 教师；
- 科目；
- 年级；
- 教室类型；
- 教室；
- 班级。

界面可先导出带中文表头的 CSV 或 Excel 模板。Excel 模板包含“导入模板”和“字段说明”两个工作表。

教室可按“教室类型名称”引用现有类型；班级可按年级名称、学期名称、班主任姓名和默认教室名称引用现有数据。引用必须在本地唯一匹配，否则对应行不能确认。

## 2. 流程

1. 选择数据类型并通过 Tauri 原生打开对话框选择 `.csv` 或 `.xlsx`；
2. sidecar 将原文件原子复制到项目 `attachments/imports/`，不保存外部绝对路径；
3. 自动识别中文或英文字段，并返回最多 50 行预览；
4. 用户可把每个源表头映射到目标字段、忽略不需要的列，并重新预览；
5. XLSX 有多个工作表时可切换工作表重新预览；
6. 错误数为零且至少有一条有效记录时才允许确认；
7. 确认时重新计算附件 SHA-256/大小并重新解析全部数据；
8. 强制创建 `pre-import` 完整备份；
9. 使用 `expected_revision` 和单个 SQLite 事务写入，任一行违反唯一性、引用或范围规则则整批回滚；
10. 成功后记录导入数量、新 Revision 和操作前备份 ID。

预览和放弃预览不修改业务 Revision。

## 3. 文件与内容限制

- 原文件最大 20 MiB；
- 最多 100,000 行、50 列；
- 单元格最大 10,000 字符；
- CSV 支持 UTF-8 BOM、UTF-8 和 GB18030，自动识别逗号、分号或 Tab；
- XLSX 内部文件最多 2,000 个，解压体积最多 200 MiB，单项压缩比最多 1,000；
- 拒绝 XLSX 内部路径穿越；
- 拒绝 Excel 公式，只允许静态值，避免外部链接或公式执行语义进入项目；
- CSV/XLSX 导出会对以 `= + - @` 开头的文本添加防公式注入前缀。

## 4. 数据校验

- 必填名称不能为空；
- 同一文件内名称不得重复；
- 本地已存在同名记录时拒绝插入，不做隐式覆盖；
- 状态映射为 `active/inactive`；
- 数值、布尔值和正整数按目标字段校验；
- 多个源字段不能映射到同一目标字段；
- 必填目标字段必须被映射；
- 未映射但含值的列作为警告显示，不阻断确认。

## 5. 本地接口

- `POST /v1/imports/preview`：复制并预览外部文件；
- `POST /v1/imports/{id}/remap`：按新字段映射或工作表重新预览；
- `POST /v1/imports/{id}/confirm`：强制备份后确认事务导入；
- `POST /v1/imports/{id}/abandon`：放弃预览；
- `GET /v1/imports`：列出导入记录；
- `POST /v1/imports/template`：生成本地化 CSV/XLSX 模板。
