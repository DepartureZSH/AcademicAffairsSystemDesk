# 按对象分配作息模板

## 1. 模块结论

桌面版现在可以为班级、教师、科目、教室、教室类型和全局回退对象分配本地作息表。分配记录进入版本化 SQLite、通用 revision API、排课数据快照和桌面“学期与作息”界面；修改分配后旧候选会按既有机制标记为基于旧数据。

## 2. 排课解析顺序

每个教学任务独立解析有效作息，顺序与网页版当前编译逻辑一致：

1. 班级分配；
2. 主讲教师分配；
3. 科目分配；
4. `all` 全局回退分配；
5. 与任务学期匹配的默认作息。

求解器只为该任务的课次生成所选作息表中的活动课节。绑定到其他作息表的教师、班级、课次或教室可用性规则不会错误作用于当前任务。教室及教室类型分配先完整保存在本地，用于对应维度课表展示和后续网页版数据迁移；它们不会越过班级主排课网格改变课程时间。

## 3. 数据约束

`timetable_template_assignments` 强制：

- 实体类型只能是 `homeroom/teacher/subject/room_type/room/all`；
- `all` 的实体 ID 必须为空，其他类型必须有 ID；
- 作息表使用 SQLite 外键并随作息删除级联清理；
- 同一实体最多一条有效分配；
- 通过桌面 API 保存时，实体 ID 必须在对应本地表中真实存在。

## 4. 验证

自动测试覆盖非法对象拒绝、全局分配 ID 归一化、V1→V2 表迁移，以及班级绑定特殊作息后，全部候选课次只能落在特殊作息的星期和 slot 范围内。该表也进入候选输入快照，因此候选可重现性哈希包含完整分配关系。
