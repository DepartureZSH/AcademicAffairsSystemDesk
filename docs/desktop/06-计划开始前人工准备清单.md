# 计划开始前人工准备清单

> 这是按工作流分层的人工 Gate 记录，不是必须一次性完成的总清单。请在进入相应工作流前，将相关项从 `[ ]` 改为 `[x]`，并填写证据或批准例外。不要把密码、私钥、token 或未脱敏数据库发送到聊天或提交 Git。

## 1. Gate 使用规则

- `G0`：开始本地桌面主体开发前必须完成，只包含独立仓库和可用的本机构建环境。
- `G1`：接入远程身份、许可证、SMTP 和支付前必须完成；不阻塞本地排课功能。
- `G2`：生成并发布自签名 Windows 测试安装包前必须完成；不阻塞开发构建。
- `G3`：申请 SignPath Foundation 和正式签名发布前必须完成。

某 Gate 未通过只阻塞其对应工作流，不向前扩大为项目总阻断。允许例外时必须写明风险、临时措施、负责人和截止日期。以下项目若标记“阻断”，不得在对应工作流中以例外跳过：现有改动归属、生产与测试环境隔离、备份恢复、支付权威定价/幂等、任何私钥不入库。
