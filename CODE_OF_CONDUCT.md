# Code of Conduct

## Our standard

Project participants must communicate respectfully, evaluate contributions on technical merit, protect user privacy and avoid harassment, discrimination, threats, impersonation or disclosure of another person's private information.

## Project and signing integrity

Participants must not introduce malware, unwanted software, credential collection, proprietary code presented as open source, undisclosed network behavior or artifacts intended to bypass the project's build and signing controls. Security concerns should be reported privately under `SECURITY.md`.

## Enforcement

Maintainers may edit or remove abusive content, close contributions, restrict participation or revoke repository and signing access when necessary. Reports about participant conduct may be sent privately through the repository's Security Advisory mechanism. Good-faith reports will be handled as confidentially as practical.

This policy applies in project repositories, issue trackers, review discussions, release channels and other spaces where a participant represents the project.
