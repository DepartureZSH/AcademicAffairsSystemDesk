# 时奕教务排课 v0.2.7 内测版

- 接入 Gitee 公开版本查询，检查结果和更新说明通过弹窗显示。
- 发现新版后在桌面端自动下载，展示进度，支持失败重试和后台下载。
- 更新包通过 Tauri 签名校验后，用户确认退出安装；安装前安全关闭项目和本地服务。
- 无需在客户端配置 Gitee 访问令牌；签名校验失败不会执行安装。
- 增加已签名更新清单生成和发布说明。

## 安装提示

旧版（v0.2.6 及以前）的检查更新为模拟模式，需要手动安装本版一次。之后可通过应用内“检查更新”获取新版本。

安装包附带 Tauri 自动更新签名，不代表已获得 Windows Authenticode/SignPath 签名；Windows 仍可能显示未知发布者提示。

下载包暂存在内存中，退出应用后需要重新下载，不支持断点续传。升级前请保存当前工作并停止排课。
