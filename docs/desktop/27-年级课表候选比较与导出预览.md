# 年级课表、候选比较与导出预览

## 1. 模块结论

课表工作台现已覆盖班级、教师、教室和年级四种查看范围，并可在同一范围内比较任意两个候选。CSV、Excel 和 PDF 导出前可以预览并设置范围、全部/单周/双周、横向/纵向和彩色/黑白；Problem XML 和 Solution XML 始终保持候选绑定的原始算法制品，不应用展示筛选。

## 2. 年级课表

本地查询通过课表条目的班级关联到 `homerooms.grade_id`，筛选列来自固定白名单，不接受客户端 SQL 片段。选择年级后，界面只显示该年级所有班级的课次；未选择具体对象时仍显示全部课表。

## 3. 候选差异

用户以当前候选为基线选择第二个候选。比较在本机按不可变 `task_lesson_id` 对齐，并统计：

- 时间、教室或周次发生变化；
- 对比候选新增的课次；
- 对比候选缺失的课次；
- 位置完全不变的课次；
- 对比候选相对基线的总得分差。

比较复用当前年级/班级/教师/教室范围，不创建新候选、不修改数据库，也不上传任何条目。

## 4. 导出预览与实际行为

界面在打开系统保存对话框前显示预计条目数和选项。API 对所有选项使用枚举校验：

- `entity_type`：`teacher`、`homeroom`、`room`、`grade`；类型与 ID 必须同时存在；
- `week_mode`：`all`、`odd`、`even`；
- `layout`：`landscape`、`portrait`；
- `color_mode`：`color`、`grayscale`。

单/双周导出会将周次位图中另一奇偶性的位清零，并排除在目标奇偶周完全没有课的条目。CSV 和 Excel 保留处理后的周次位图；PDF 只展示目标范围条目。PDF 真正切换 A4 横纵版式与配色，Excel 切换表头配色并在“候选信息”页记录全部选项。

每次导出的 `summary.viewOptions` 保存实际选项、条目数、哈希和目标路径状态，便于审计和复现。

## 5. 原始 XML 边界

Problem XML 是候选输入快照编译出的算法问题，Solution XML 是候选完整求解结果。对它们应用筛选会破坏可重放性，因此 XML 导出忽略展示选项，并在导出摘要标记 `rawArtifact=true`；界面同时禁用版式、颜色和单双周控件并解释原因。

## 6. 验收

- 年级筛选只返回关联班级课次；
- 两候选比较不依赖课表行 ID，只依赖稳定课次 ID；
- 单周测试位图由 `11111111111111111111` 变为 `10101010101010101010`；
- 纵向、黑白 Excel 在候选信息中记录 `odd / portrait / grayscale`；
- 只传筛选类型、不传对象 ID 时明确拒绝；
- CSV/XLSX/PDF/XML 原有导出、原子覆盖和中文文件名测试继续通过；
- Vue 生产构建和 Python 导出/API 测试通过。
