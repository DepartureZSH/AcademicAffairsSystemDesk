## 6. 明确保留的边界

本发布不能称为生产正式版：

- 身份仅连接本机 Docker Supabase；
- 许可证、支付、SMTP 和远程更新仍在 `config/services.yaml` 中明确为 Mock；
- Sealos 生产 Supabase、Karios Pay 生产加固、企业 SMTP 和 `updates.karios.tech` 尚未接入；
- SignPath Foundation 仍待申请/审批，本版 Publisher 是测试自签名证书；
- 原生 Windows 10 x64、原生 Windows 11 x64 和“10 秒内窗口可交互”仍需人工抽检；
- Windows 11 ARM64 上的 x64 仿真结果不得冒充原生 Windows 11 x64 证据。

达到上述外部与人工门槛前，只能继续发布明确标记的测试版本。
