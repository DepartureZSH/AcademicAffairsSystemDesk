# v0.1.12 依赖许可证元数据核对

`buffers@0.1.1` 是 ExcelJS → unzipper → binary 的传递依赖。该旧 npm 包没有发布 license 字段，不能直接将“无字段”当作无条件许可，也不能让检查器跳过所有未知许可。

[Debian 对 node-buffers 0.1.1-2 的源包版权记录](https://sources.debian.org/copyright/license/node-buffers/0.1.1-2/) 保存了 MIT 声明，并明确引用上游 `package.json` 提交 `1b745ee35d33eb166e15ef1866073a07c6d7de87`。上游原仓库当前无法访问；本次依据该存档补充元数据，不声称重新获取了原仓库。

清单生成器仅为 `buffers@0.1.1` 设置版本限定的已核对元数据，保留许可证来源和上游提交；其他缺失许可仍导致失败。没有修改 npm 包代码或依赖版本。

本项目使用 ExcelJS 的浏览器预构建文件；其 source map 的 534 个源码条目中没有 `node_modules/buffers/`。完整依赖清单仍列出此 npm 安装依赖，不把清单等同于所有代码均进入安装包的证明。
