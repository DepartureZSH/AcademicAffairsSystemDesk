# 时奕教务排课 v0.2.9 内测版

- 优化恢复工作区速度：本地服务依赖在安装时释放，避免每次启动重新解压。
- 服务启动移到后台线程，健康检查和项目列表读取并行执行，减少界面等待。
- 保留中文启动入口、许可证门禁、项目完整性检查和本地数据保护。

本机空工作区测试：旧版服务就绪约 17.1 秒，新版首次约 8.0 秒，后续约 1.25 秒。结果受磁盘缓存、安全软件和设备性能影响，不包含远程身份核验或大型项目读取时间。

## 更新说明

v0.2.7/v0.2.8 可在应用中点击“检查更新”。请先保存工作、停止排课，下载并通过校验后选择“退出并安装”。更早版本需手动安装。

本版新增安装目录下的 `_internal` 运行库目录，请勿删除或只拷贝后台 EXE。项目工作目录不变，建议升级前备份项目。

安装包附带 Tauri 更新签名；尚未使用 Windows Authenticode/SignPath 签名，系统仍可能提示未知发布者。
