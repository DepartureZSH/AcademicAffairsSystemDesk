# 用户工作目录与项目关闭实现

## 1. 模块结论

桌面端现在允许用户通过系统目录选择器指定项目工作目录。选择结果只保存为当前设备的本地设置，随后由 Rust 可信层规范化并传给 sidecar；sidecar 仍只在该目录下管理自己的项目子目录。学校、教师、课表等业务数据不会进入 WebView 设置。

用户也可以显式关闭当前项目。关闭只释放 SQLite 连接和项目锁，不删除项目、附件、候选、备份或归档。

## 2. 首次与日常启动

- 从未选择目录时使用 Tauri 的应用数据目录下 `Workspace` 作为安全默认值。
- 用户选择目录后，下次启动自动复用该路径。
- Rust 创建目录并执行 `canonicalize`，sidecar 收到的是绝对规范路径。
- 当前实际路径持续显示在项目工作台，便于备份、迁移与故障定位。

路径设置不是密码或授权凭据，因此不进入 Credential Manager；它只保存在本机 WebView localStorage。登录令牌、设备私钥和授权凭证仍只由 Rust 安全存储层读取。

## 3. 切换安全性

切换目录前必须经过系统确认对话框，明确展示目标路径以及“不会移动或删除原项目”。确认后按以下顺序执行：

1. 关闭当前项目并停止 sidecar；
2. 保存新目录设置；
3. 使用新目录重启 sidecar并刷新项目列表；
4. 若新目录不可创建、不可规范化或 sidecar 启动失败，恢复原设置并尝试重启原工作区。

排课进程运行时，sidecar 会拒绝关闭项目；因此切换不会强行留下半成品候选。

## 4. 项目关闭

“关闭当前项目”会显示项目名和工作目录并要求确认。成功后：

- SQLite 连接与项目锁释放；
- UI 回到项目工作台；
- 本机项目仍出现在最近项目列表；
- 文件内容和 revision 不变；
- sidecar 保持运行，可立即打开另一个项目。

## 5. 验收

- Vue 生产构建必须通过。
- 默认目录和自选目录都能创建项目。
- 切换到新目录后项目列表彼此隔离。
- 切换失败时原路径设置恢复。
- 关闭项目后健康状态 `projectOpen=false`，重新打开后 revision 与实体数据一致。
- 卸载应用不处理用户选择的工作目录。
