# v0.2.3 本地测试版

## 本次更新

- 登录状态默认保留 7 天，自动刷新短期会话；主动退出或会话被撤销后重新登录。
- 新增账号菜单和服务异常页面的“重启本地服务”入口。
- 会员核验恢复后自动恢复本地服务和已打开项目；后台计时器暂停后先重新核验，避免仅因缓存到期就停止服务。
- 教室取消独立导出模板设置，沿用教室类型配置。
- 科目配置仅选择教室；期望时间使用完整网页版样式，并遵循模板隐藏星期。
- 新课长以分钟保存，按实际节次时长筛选候选；原有课次保留兼容处理。

## 升级说明

安装前保存并退出旧版，运行本版本安装包，沿用原安装目录。
升级保留工作目录中的项目。首次打开旧项目会先备份，再迁移至 SQLite schema 5；教室原来的独立模板绑定在迁移时移除，改由教室类型管理。
7 天自动登录不等于离线授权，会员权益仍需联网核验。
本次为本地测试安装包，不用于自动更新渠道发布。
