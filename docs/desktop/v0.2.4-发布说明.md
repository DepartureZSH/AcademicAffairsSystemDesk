# v0.2.4 本地测试包

本次重新打包包含 v0.2.3 的本地服务恢复和登录保留改动，以及新增 AI 设置和 AI 助手页面。

- AI 设置：自配 API 地址、密钥与模型；系统密钥库保存；单独确认后测试连接。
- AI 助手：复刻网页版五个场景页签、提示词库、附件入口、专用向导和全屏布局，保留数据去向提示。
- 基础对话：通过桌面端请求自选服务，仅发送用户确认的对话和附件，不自动上传整个项目。
- 本地 Excel 读取与 Markdown 表格显示；修正 AI 设置按钮对齐。

## 已知限制

这不是网页版 AI 功能全量迁移完成版。课表 AI 分区生成及草稿保存、约束搜索与确认执行、批量期望时间保存、官方模板下载、审计持久化和流式回复仍未接通。未接通的操作明确报错，不修改项目数据。

AI 对话暂存在当前页面会话内，离开页面前请保存重要内容。未使用真实用户 API Key 验证第三方调用全链路。

## 安装

优先使用 x64 NSIS 安装程序；MSI 作为备用。安装前保存并退出旧版应用。此次仅生成本地安装包，不自动替换已安装应用、不推送 GitHub，也不切换 SignPath 签名。
