# 课次编辑与教师字段迁移

本次修改随 v0.2.1 测试版发布，不替换已有 v0.2.0 安装包。

## 教师数据

教师新增、详情、导入模板和导入映射不再包含工号。SQLite schema 从 2 升级到 3，通过迁移删除 `teachers.employee_no`，保留教师 ID、姓名、分组及现有班主任/授课任务关联。历史 schema 1 定义保留原字段，以便从旧项目逐级迁移。

旧项目打开时先生成并校验 `pre-migration` 备份，再执行迁移。旧版应用不支持 schema 3；如需返回旧版本，应使用迁移前备份，不要直接打开升级后的项目。已有备份不会被擦除，因此仍可恢复旧工号。

## 科目配置

- 编辑课次：新增、命名、启停、复制、删除、设置连续节数、默认/自定义候选教室。
- 期望时间：按本班分配的课表模板展示候选课节，选择全部周、单周、双周或具体周；提供最高、普通、较低、兜底和绝对不排五档，与网页优先级数值一致。
- 未设置候选时默认全部可行时间。设置候选后，算法在选定的课节/周频率组合中选择；禁排始终优先，无可用时间返回明确诊断。连续节数沿用本地排课单位，不把分钟数直接当作节数。
- 时间面板“确认”及课次面板“完成并返回”只修改草稿；“保存授课任务”才原子写入任务和课次。
- 保留既有课次 ID；删除课次会清理其时间规则，被约束引用的课次必须先解除引用。保存失败全部回滚，旧版本号提交会被拒绝。
- 复制班级时继承课次期望时间，清空课次自定义教室，避免误用来源班级教室。
- 历史导入的 availability 时间规则继续参与排课，不会被新的课次设置覆盖。新面板维护的是本次新增的课次配置，不声称已重现网页的所有高级时间编辑操作。

## 验证

Python 覆盖 schema 迁移/备份、教师关联保留、课次 ID 保留及重排、事务回滚、过期版本/非法输入、禁排和候选编译、课次教室、引用保护。

浏览器实际验证完整遮罩（1360×900、700×800）、课次时间保存及读回、取消不落库、背景点击不关闭，表格计数与搜索控件垂直居中。测试使用独立开发项目中的专用临时记录，完成后按记录 ID 清理，不操作正式项目。
