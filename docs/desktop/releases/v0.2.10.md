# 时奕教务排课 v0.2.10

本次为发行资源清理更新。

- Windows 安装包不再携带开发用的 `mock/purchase.html` 模拟购买页面；真实会员购买入口不变。
- NSIS 安装升级时清理旧版遗留的模拟购买页面，仅在目录为空时移除 `mock` 文件夹，不删除其他文件。
- 开发测试样例仍保留在源码仓库，不随发行版发布。
- 延续 v0.2.9 的本地服务启动优化；`_internal` 是后台服务运行依赖，请勿删除。

提供 Windows x64 NSIS、MSI 安装包及独立的 Tauri 自动更新签名。已安装支持自动更新的版本可通过应用内“检查更新”获取本次更新。

本次未切换 SignPath/Authenticode 签名；Tauri 自动更新签名用于校验更新包完整性和来源，不等同于 Windows 发行者证书。
