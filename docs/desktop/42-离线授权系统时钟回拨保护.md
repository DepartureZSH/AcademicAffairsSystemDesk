# 离线授权系统时钟回拨保护

## 1. 模块结果

Rust 授权门禁使用 Windows Credential Manager 保存 `license-clock-checkpoint`。每次校验本地授权时读取最大已见 Unix 时间：

- 当前时间正常前进时，检查点推进到当前时间；
- 回拨不超过5分钟时，视为系统自动校时误差；
- 回拨超过5分钟时，许可证立即变为不可用，Sidecar 不启动，并要求联网校验；
- 回拨失败不会覆盖较新的检查点；
- 退出登录只清除会话和授权，不删除设备私钥及时间检查点。

当前许可证服务为 Mock，用户可重新输入公开测试企业密钥恢复测试授权并重置检查点。切换真实许可证服务后，只有成功在线续签或激活才能重置检查点。

## 2. 安全边界

检查点只保存一个时间整数，不包含账号、教务数据、JWT、企业密钥或设备私钥。值位于系统凭据库，不写入项目 SQLite、YAML、日志或 WebView。

本机制用于识别“明显回拨”，不把本机时钟当成绝对可信时间源。生产服务仍需通过短期 Ed25519 JWS、服务端撤销状态和在线续签共同限制最长7天离线窗口。

## 3. 验证

Rust 单元测试覆盖：无检查点、时间前进、恰好5分钟容差和超过容差1秒。既有授权篡改、账号/设备绑定与 Sidecar 门禁逻辑继续执行。
